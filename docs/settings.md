# Dashboard และการตั้งค่า

เปิด `http://<hub>:7880` แล้วใส่รหัส dashboard การตั้งค่าเก็บใน hub และส่งถึงทุก agent ทันที ไม่ต้อง restart

## Overview

- **Join token**: copy หรือสร้างใหม่ token ใหม่ไม่กระทบเครื่องที่ join ไว้แล้ว
- **ผังจอ**: ลากจอให้ตรงกับตำแหน่งจริง ขอบจะดูดติดกันเอง แล้วกด *Save layout* เครื่องที่ away แสดงเป็นกรอบเส้นประ
  ถ้าผังทำให้ข้ามจอไม่ได้ จะมีข้อความสีแดงใต้ผังและในแถวของเครื่อง ดู [เมื่อจอของเครื่องเปลี่ยน](#เมื่อจอของเครื่องเปลี่ยน)
- **Machines**: สถานะ (online, away, offline), OS, จอ, เวอร์ชัน, ความเร็วเมาส์ของแต่ละเครื่อง, ปิดใช้งาน, เปลี่ยนชื่อ
  ปุ่ม **Remove** ยกเลิกสิทธิ์ของเครื่องนั้นทันที
- **Paths**: เส้นทางของแต่ละคู่เครื่อง (p2p หรือ relay) และ RTT

## เมื่อจอของเครื่องเปลี่ยน

เสียบหรือถอดจอ หมุนจอ หรือเปลี่ยนความละเอียด agent จะส่งรายการจอใหม่ให้ hub เอง ไม่ต้อง restart
(GNOME: ฟังสัญญาณ `MonitorsChanged` ของ GNOME ถ้าไม่มีจะเช็คทุก 10 วินาที, X11: RandR, Windows: `WM_DISPLAYCHANGE`)

hub จัดผังใหม่ตามกฎนี้:

1. เครื่องที่จอเปลี่ยนอยู่ที่เดิม
2. เครื่องที่เคยชิดขอบด้านไหนของมัน ขยับตามขอบด้านนั้น เช่น PC ที่อยู่ขวาของ laptop จะอยู่ขวาของ laptop ต่อไปทั้งตอนเสียบจอเพิ่ม (กว้างขึ้น) และตอนถอดจอ (แคบลง)
   เครื่องที่ชิดกับ PC อยู่ก็ขยับไปด้วยกันทั้งแถว ถ้าหลังขยับแล้วไม่ตรงกันเลย จะเลื่อนให้ขอบบน (หรือขอบซ้าย) ตรงกัน
3. ถ้ายังมีเครื่องทับกัน จะดันเครื่องที่ทับออกไปทางที่ใกล้ที่สุดจนขอบชิดกันพอดี

เครื่องที่ไม่ได้ชิดและไม่ได้ทับจะไม่ถูกย้าย ใต้ผังจอบอกว่าย้ายเครื่องไหนไปไหน (แสดง 10 นาที) และ log ของ hub ก็บันทึกไว้
ถ้าผังที่ได้ไม่ตรงกับโต๊ะจริง ลากใหม่แล้วกด *Save layout* ได้เลย

dashboard เตือนเป็นสีแดงเมื่อ:

- **เครื่องทับกัน**: ไม่มีขอบให้ข้ามระหว่างสองเครื่องนั้น ลากแยกจนขอบชิดกัน
- **เครื่องที่ online ไม่ชิดเครื่องไหนเลย** เช่น "SONTY-PC does not touch any other screen": ลากไปชิดเครื่องอื่น

ระหว่างลาก ข้อความเตือนคิดจากตำแหน่งที่ยังไม่ save (มีคำว่า unsaved)
หน้าต่างสถานะของ tray บนเครื่องที่ไม่มีขอบไปเครื่องไหนเลยแสดง *No edges to other machines (check the layout in the dashboard)*

## Settings

ค่าส่วนใหญ่ตั้งได้สองระดับ คือค่ากลาง และค่าของแต่ละเครื่องในตาราง Per-machine settings
ค่าของเครื่องชนะค่ากลางเสมอ เลือก *inherit* เพื่อกลับไปใช้ค่ากลาง

| การตั้งค่า | ทำอะไร |
| :--- | :--- |
| Emergency hotkey | ดึงการควบคุมกลับเครื่องตัวเอง |
| Clipboard | เปิดหรือปิด แยกข้อความกับรูป และขนาดสูงสุด |
| Edge behaviour | หน่วงก่อนข้าม, ต้องชนขอบสองครั้ง, มุมจอที่ไม่ข้าม |
| Input path | ใช้ P2P ก่อน หรือบังคับผ่าน hub, ระยะห่างการเช็คเส้นตรง |
| [Allowed networks](#วงที่อนุญาต) | ใช้งานได้เฉพาะตอนอยู่ในวงที่กำหนด |
| [Crossing key](#ปุ่มข้ามจอ) | ต้องกดปุ่มค้างไว้ถึงจะข้ามจอ |
| [Cursor](#เคอร์เซอร์ตอนคุมเครื่องอื่น) | เคอร์เซอร์ของเครื่องตัวเองไปอยู่ไหนตอนคุมเครื่องอื่น |
| [Agent updates](updates.md#policy) | automatic, notify หรือ off |
| Log level | ระดับ log ของ agent |

ค่าที่ผิดรูปแบบ เช่น CIDR `10.10.15.0/33` หรือชื่อปุ่มที่ไม่รู้จัก จะไม่ถูกบันทึก และมีข้อความบอกว่าผิดตรงไหน

## วงที่อนุญาต

ใช้แก้ปัญหา laptop ที่ออกนอกบ้านแล้วต่อ VPN กลับมา ถ้าไม่จำกัด เลื่อนเมาส์ชนขอบจอก็ไปคุมเครื่องที่บ้านได้

ใส่ CIDR บรรทัดละรายการ เช่น `10.10.15.0/24` ปล่อยว่างคือไม่จำกัด (ค่าเริ่มต้น)

agent ตัดสินจาก IP ของ network interface ในเครื่องตัวเอง ไม่ใช่ IP ที่ hub เห็น
ถ้า interface ใดมี IP อยู่ในวงที่อนุญาต ถือว่าอยู่บ้าน VPN จึงไม่ทำให้นับว่าอยู่บ้าน เพราะ IP ของ VPN อยู่คนละวง
agent เช็คทุก 3 วินาที ดู IP ที่ agent เห็นได้ด้วย `flow-agent status`

เครื่องที่อยู่นอกวงจะเป็น **away**: ข้ามจอไม่ได้ทั้งไปและมา ไม่ซิงก์คลิปบอร์ด ปุ่มที่กดค้างถูกปล่อย
แต่ยังต่อ hub อยู่ dashboard จึงแสดงสถานะและ IP ปัจจุบันได้ กลับเข้าวงเมื่อไหร่ก็ใช้งานต่อได้เอง

ถ้าเครือข่ายนอกบ้านบังเอิญใช้ช่วง IP เดียวกับที่บ้าน agent จะนับว่าอยู่บ้าน ให้เลือกช่วงที่ไม่ซ้ำกับที่อื่น

## ปุ่มข้ามจอ

ใช้ตอนเล่นเกม FPS ที่เมาส์ชนขอบจอบ่อย ปล่อยว่างคือข้ามได้อิสระ (ค่าเริ่มต้น)
ตั้งเป็นปุ่มที่ต้องกดค้างไว้ตอนเมาส์ถึงขอบจอ:

- modifier: `Ctrl`, `Alt`, `Shift`, `Win` (ข้างไหนก็ได้) หรือระบุข้าง เช่น `LeftCtrl`, `AltGr`
- คอมโบ: `Ctrl+Alt`
- ปุ่มทั่วไป: `CapsLock`, `ScrollLock`, `F13`, ตัวอักษร

ใน dashboard กด **Record** แล้วกดปุ่มที่ต้องการ หรือพิมพ์ชื่อปุ่มเองก็ได้

ข้อควรรู้:

- ปุ่มนี้ใช้ทั้งตอนไปและตอนกลับ เกมบนเครื่องปลายทางจึงไม่หลุดเหมือนกัน emergency hotkey ยังดึงกลับได้เสมอ
- ตัวปุ่มข้ามจอไม่ถูกส่งไปเครื่องปลายทาง ถ้าตั้งเป็น Ctrl แล้วอยากกด Ctrl+C ที่ปลายทาง ให้กด Ctrl ใหม่หลังข้ามไป
- **บน GNOME (Wayland)** ให้ดันเมาส์ชนขอบก่อน แล้วค่อยกดปุ่ม เพราะ GNOME ไม่บอก agent ว่ามีปุ่มกดค้างอยู่ก่อนเมาส์ถึงขอบ
  ระหว่างดันขอบ ถ้าเลื่อนกลับ หยุดดัน 0.3 วินาที หรือกดปุ่มอื่น เมาส์จะกลับมาที่เดิม
  ปุ่มหรือคลิกครั้งแรกนั้นจะไม่ส่งถึงโปรแกรมบนเครื่อง
- บน Windows และ X11 กดปุ่มค้างไว้ก่อนแล้วค่อยเลื่อนไปชนขอบได้ตามปกติ

## เคอร์เซอร์ตอนคุมเครื่องอื่น

| ตัวเลือก | เคอร์เซอร์ของเครื่องตัวเอง |
| :--- | :--- |
| Stay at the edge (ค่าเริ่มต้น) | อยู่ตรงขอบที่ข้ามออกไป |
| Move to the centre | ย้ายไปกลางจอที่ข้ามออกไป |
| Move to the centre and hide | ย้ายไปกลางจอและซ่อนไว้ |

ทุกตัวเลือก พอข้ามกลับมา เคอร์เซอร์จะเข้ามาที่ขอบจอตรงตำแหน่งที่ข้ามมา
ถ้ากลับด้วยทางอื่น เช่น emergency hotkey, pause, เครื่องปลายทางหลุด หรือ agent หยุด เคอร์เซอร์จะแสดงตรงที่มันอยู่
agent crash ก็ไม่ทำให้เคอร์เซอร์ซ่อนค้าง

ทำได้แค่ไหนในแต่ละระบบ:

- **Windows**: ทำได้ทุกตัวเลือก การซ่อนใช้หน้าต่างโปร่งใสเล็กๆ ของ agent วางใต้เคอร์เซอร์ ไม่แก้เคอร์เซอร์ของระบบ
  ถ้าเกมเต็มจอแบบ exclusive มีปัญหากับหน้าต่างนี้ ให้ใช้ *Move to the centre* แบบไม่ซ่อน
- **X11**: ทำได้ทุกตัวเลือก
- **GNOME (Wayland)**: ทำได้แค่ *Stay at the edge* เพราะ GNOME ตรึงเคอร์เซอร์ไว้ที่ขอบระหว่าง capture และไม่มี API ให้ย้ายหรือซ่อน
  dashboard จะบอกข้อจำกัดนี้ใต้ชื่อเครื่อง

## Emergency hotkey

ค่าเริ่มต้น **Ctrl+Alt+Shift+Esc** กดบนเครื่องที่กำลังคุมเครื่องอื่น การควบคุมจะกลับมาที่เครื่องนั้นทันที และปุ่มที่กดค้างที่ปลายทางจะถูกปล่อยก่อน
ตั้งเป็นชื่อปุ่มคั่นด้วย `+` อย่างน้อยสองปุ่ม เช่น `Ctrl+Alt+F12`

กันปุ่มค้างด้วยอีกสองชั้น: เครื่องที่ถูกคุมปล่อยทุกปุ่มเองถ้าไม่ได้ยินจากต้นทาง 2.5 วินาที
และเครื่องต้นทางดึงการควบคุมกลับเองถ้าไม่มีเส้นทางไปปลายทาง 1.5 วินาที

## ไฟล์ config ของ agent

Linux: `~/.config/flowcursor/agent.toml` · Windows: `%APPDATA%\flowcursor\config\agent.toml`
ไฟล์นี้เก็บเฉพาะค่าที่ต้องใช้ได้แม้ hub ล่ม ค่าอื่นมาจาก hub ทุกค่าไม่บังคับ

```toml
hub = "192.168.1.10"              # host หรือ host:port, ไม่ใส่ = หาด้วย mDNS
p2p_port = 7879                   # UDP สำหรับ P2P, 0 = สุ่ม
# p2p_advertise = ["192.168.1.20:7879"]   # ที่อยู่ที่เครื่องอื่นใช้ติดต่อเครื่องนี้ (NAT, หลาย NIC)
backend = "auto"                  # auto, wayland, x11, windows, sim
# emergency_hotkey = "Ctrl+Alt+Shift+Escape"
# log_level = "info"
# log_file = "/tmp/flow-agent.log"
# state_dir = "/path"             # ค่าเริ่มต้น ~/.local/share/flowcursor
```

agent เขียนตัวตนของตัวเองไว้ใน `state_dir` (`agent.crt`, `agent.key`, `agent-state.json`) สิทธิ์ 0600

ถ้า hub ล่ม agent ใช้ผังจอและที่อยู่เครื่องอื่นล่าสุดที่จำไว้ คุมกันผ่าน P2P ต่อได้ แต่ส่งผ่าน hub ไม่ได้จนกว่า hub กลับมา
