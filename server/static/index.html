Network and crossing

CIDR blocks, one per line (IPv4 or IPv6), e.g. 10.10.15.0/24. A machine shares mouse, keyboard and clipboard only while one of its own network interfaces has an address inside a block; otherwise it is away (stays connected, shown in the dashboard). A VPN address (e.g. 10.8.0.5) is not inside the home block, so the VPN alone never counts as home.
Hold this key (or combo) while the pointer reaches an edge to switch machines; without it the pointer stays at the edge (useful for games). Applies when leaving a machine's screen, also on the way back. Empty = cross freely.

Per-machine settings

Each machine inherits the global allowed networks and crossing key, or uses its own. Rename, enable/disable, mouse speed and removal (credential revocation) are on the Overview tab.
